# After Hours Athens

A nightlife guide to bars, restaurants, and live music in Athens, GA.

## How to run
1. Open this folder in VS Code (File > Open Folder).
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

A local server is needed because the pages load venue data from `data.json`.

## Files
- `index.html`: home page
- `bars.html`, `restaurants.html`, `live-music.html`: guide pages
- `style.css`: all styling
- `script.js`: loads, filters, and groups the venues
- `data.json`: venue data
